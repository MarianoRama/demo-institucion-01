# Demo de landing institucional

Vista previa de demostración de un sitio bilingüe (ES/EN) para una institución educativa. No incluye nombre, logo, dirección, teléfono, correo ni fotos reales de ninguna institución — todos esos datos están marcados como "a confirmar" o reemplazados por imágenes de stock rotuladas como muestra.

## Ejecutar

```sh
npm install
npm run dev
```

## Stack

Astro (sitio estático), sin backend ni base de datos. Deploy automático a GitHub Pages vía GitHub Actions.
